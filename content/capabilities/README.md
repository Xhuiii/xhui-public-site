# Public capabilities / 公开能力

Use this directory for capabilities supported by public evidence, not for private self-evaluation or unverified aspirations.

本目录用于存放有公开证据支持的能力，不用于存放私人自评或尚未验证的愿望。

Prefer a concise capability statement followed by a project, artifact, or observable result that supports it.

优先使用“简洁能力描述 + 对应项目、作品或可观察结果”的结构。
