# Public projects / 公开项目

Use this directory for finished, externally understandable project stories.

本目录用于存放已经完成、外部读者可以理解的项目案例。

Each project should explain the context, contribution, outcome, evidence, and what can be shared publicly. Remove private names, confidential data, credentials, and unverified claims before review.

每个项目应说明背景、个人贡献、结果、证据，以及哪些内容允许公开。审查前删除私人姓名、保密数据、凭证和未经验证的表述。
